# V9 — Tactical Combat Overhaul

- Replaced the full solar-system arena with the giant-planet **Shattered Frontier** map and four destructible moons.
- Added breakable relay structures and denser large-asteroid cover.
- Enlarged planetary scale dramatically; reduced all ship max speeds and acceleration.
- Added independent first-person 3D cockpits with per-camera render layers, and chase/cockpit toggles for both pilots.
- Rebuilt target selection around aim alignment; added HUD brackets, predictive lead, offscreen marker, target health/shields, range and relative speed.
- Added time-dependent thermal lock, aim-cone and line-of-sight checks, missile ammunition limits, guided turn-rate caps, flares and incoming threat detection.
- Added layered 3D laser bolts, guided missile meshes, muzzle positioning, projectile trails, heat/cooldown states and impacts.
- Improved bot shot leading, missile locks, obstacle avoidance, braking and countermeasures.
- Retained 2v2, FFA, solo+bot teammate, team win rules, planetary breakup and persistent rubble fields.
- Rewrote documentation for GitHub Pages / PlayCanvas Engine deployment and added pure logic targeting tests.
